PROJECT INFORMATION

Tentang ITCare

Proyek portofolio untuk simulasi operasional IT Support.

PORTFOLIO PROJECT

ITCare — IT Helpdesk & Asset Management

Dashboard demo untuk menunjukkan alur pencatatan kendala pengguna, pemantauan status tiket, dan pengelolaan inventaris perangkat IT.

Fitur utama

  • Dashboard statistik dan grafik tiket
  • Tambah, edit, dan hapus tiket
  • Pencarian serta filter status dan prioritas
  • Ekspor data tiket ke CSV
  • Manajemen inventaris aset
  • Penyimpanan demo dengan localStorage

Teknologi

HTML5CSS3JavaScriptlocalStorageLucide Icons

Antarmuka dibuat tanpa framework frontend. Ikon menggunakan Lucide melalui CDN.

Simulasi alur kerja

  1. Pengguna melaporkan kendala teknis.
  2. Tim IT mencatat dan menetapkan prioritas tiket.
  3. Status diperbarui saat penanganan berlangsung.
  4. Tiket ditandai selesai setelah kendala teratasi.

Batasan demo

Aplikasi ini merupakan simulasi frontend. Data tersimpan di browser yang digunakan, bukan server terpusat. Login, sinkronisasi antarperangkat, dan kontrol akses belum diimplementasikan.

Gunakan data fiktif saat demonstrasi portofolio.
